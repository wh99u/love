# Мой план

Мини-приложение Telegram для денег и целей на двоих: карты и общий баланс, планировщик бюджета на месяц, машина мечты, покупки по вкладкам, календарь смен и задач. Тёмный дизайн с красным светом, матовые карточки, плавные анимации.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты логики (Vitest)
npm run build      # сборка в dist/
```

`?demo=1` в адресе открывает приложение с демо-данными. Они хранятся отдельно (`planner_demo`) и не трогают настоящие.

## Данные

Всё хранится на устройстве: `localStorage` (`planner_v4`) и IndexedDB (`planner-images`) для фото. При первом запуске записи из старой версии (`planner_v3`) переносятся автоматически, а старый ключ остаётся как резервная копия.

## Вместе (синхронизация на двоих)

Карты, пополнения, покупки и вкладки, бюджет и мечта общие; смены, задачи и настройки личные. Сервер — Firebase Firestore (бесплатный план):

1. console.firebase.google.com → новый проект → Build → Firestore Database → Create database.
2. Вкладка Rules → вставить содержимое `firestore.rules` → Publish.
3. Project settings → Your apps → Web (`</>`) → скопировать `firebaseConfig`.
4. Вставить его в `src/lib/sync/config.ts` (`BUILT_IN`) или в переменную репозитория `VITE_FIREBASE_CONFIG` — тогда оба телефона подключатся без настроек. Для проверки можно вставить и прямо в приложении: «Бюджет» → «Вместе».

Дальше: «Вместе» → «Создать общий план» → «Отправить приглашение». Партнёр открывает ссылку `t.me/<бот>?startapp=join_…` и выбирает «Объединить с моими данными». Изменения приходят сразу; без сети копятся и уходят позже. Если оба одновременно пополнили одну карту, учитываются оба пополнения.

## Покупки из магазина

Вещи можно добавить по ссылке на товар: Claude вырезает вещь с главного фото и кладёт её в `public/catalog/` (скрипт `scripts/catalog/add_item.py`, порядок — в `CLAUDE.md`). После деплоя приложение само добавит её в нужную вкладку на обоих телефонах.

## Автопополнение

iPhone не даёт приложениям читать push-уведомления банков. Поэтому быстрая команда iOS делает снимок экрана с уведомлением, находит сумму и открывает бота по ссылке `…?startapp=inc_<сумма>`. Приложение показывает готовое пополнение, остаётся нажать «Зачислить». Пошаговая инструкция есть в самом приложении: «Бюджет» → «Автопополнение».

## Деплой

При push в `main` GitHub Actions прогоняет тесты, собирает сайт и публикует его на GitHub Pages (`.github/workflows/deploy.yml`).
