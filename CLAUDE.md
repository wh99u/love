# «Мой план» — заметки для Claude

Сайт (React 19 + Vite + Motion), раньше был мини-приложением Telegram; открывается в браузере и ставится на экран «Домой». Пользователь пишет по-русски, хочет минимум вопросов и объяснений.

## Проверка

```bash
npm test          # Vitest
npm run build     # tsc + vite build
npm run dev       # http://localhost:5173/?demo=1 — демо-данные, настоящие не трогаются
```

Деплой: push в `main` → GitHub Actions → GitHub Pages.

После каждой задачи: коммит в рабочую ветку и сразу влить её в `main` и запушить (пользователь разрешил навсегда, не спрашивать).

## Дизайн

Чёрно-белый, по референсу пользователя: чёрный фон, графитовые карточки (`.surface`, `.surface--lit`), матовое стекло поверх картинок (`.glass`), белый свет вместо красного (`ui/Glow.tsx`), тонкие светлые цифры (`.t-hero`, `.grad-text`), белые кнопки (`.btn--primary`, круглые белые кнопки). Шрифт Manrope. Анимации везде плавные и пружинные (`ui/motion.ts`, `.rise` с размытием). Токены — `src/styles/tokens.css`. Контент — колонка `--col` по центру, на телефоне во всю ширину.

Главный экран — `src/screens/home/`, повторяет референс пользователя точь-в-точь (размеры сняты с выпрямленного снимка под экран 390 pt): картинка за рифлёным стеклом (`public/hero.webp` — картинка из самого референса, выпрямленная и очищенная; `FlutedGlass.tsx` рисует её по столбцам и даёт «жидкое» движение, своё фото получает полные рёбра стекла, математика в `glass.ts`), общий бюджет в стеклянном уведомлении (`BudgetNote.tsx`, нажатие переключает ₽/$ — курс ЦБ, `lib/currency.ts`, `ui/useMoney.ts`), карта (`AccountCard.tsx`, белая кнопка — пополнение/списание), бюджет месяца из планировщика (`PlanCard.tsx`).

Карта одна (`mainCard`/`cardTotal` в `lib/store.ts`): выбора карт нигде нет, карты из старых версий просто входят в баланс. Картинка карты — `Bank.imgId` (ставится в листе «Карта», синхронизируется); скачать дизайн карты Т-Банка контейнер не может — сеть закрыта.

Экран «Мечта» — по второму референсу пользователя (светлый, `src/screens/dream/`): фото машины сверху выезжает при входе, «Накоплено N%», светящиеся сегменты прогресса, белая карточка «Срок» и чёрная «В день». Машина выбирается из базы марок и моделей с русскими названиями и опечатками (`lib/cars.ts`, поиск «прош панамера» → Porsche Panamera); фото модели ищется в браузере (`lib/carPhoto.ts`, `dream/carImage.ts`): сначала вид сверху на Wikimedia Commons, иначе фото из статьи Википедии; машина вырезается из фона прямо в браузере моделью U²-Net small (`public/models/u2netp.onnx`, onnxruntime-web, `lib/carCutout.ts`) и стоит на белом фоне, в ч/б. Копия кладётся в IndexedDB и синхронизируется. Своё фото (`Car.photoFor` пусто) никогда не заменяется. Из контейнера Википедия недоступна — проверять с подменой ответов (Playwright `page.route`).

Навигация — кнопки внизу у самого края (`ui/TabBar.tsx`, без анимации появления): Главная, Мечта, Покупки, Календарь и «Ещё» — лист с инструментами (`ui/MoreSheet.tsx`: планировщик, карта, начисления, поиск, «Вместе», автопополнение, картинка главной). Кнопки «+» в углу нет: добавление — внутри экранов. Стекло на главной на касания не реагирует, только медленно «колышется». Смена ₽/$: сумма пересчитывается счётчиком, по стеклу проходит свет, подпись показывает курс; остальные суммы мягко сменяются (`ui/Swap.tsx`). Иконки интерфейса — Phosphor (`scripts/icons.mjs` → `src/ui/icons.gen.ts`), иконки товаров — свои, сплошные белые с прорезями (`src/ui/productIcons.ts`, сетка 64×64).

## Синхронизация

Общие данные (`state.shared`) синхронизируются через Firestore (`src/lib/sync/*`): каждая запись — отдельный документ, побеждает более новый `updatedAt`, а балансы карт при одновременных изменениях складываются (`merge.ts`). Конфиг Firebase — `src/lib/sync/config.ts` (`BUILT_IN`) или переменная `VITE_FIREBASE_CONFIG`. Правила — `firestore.rules`. Приглашение — ссылка на сайт `?startapp=join_<20 символов>`; автопополнение — `?startapp=inc_<сумма>` (`lib/shortcut.ts`, `appLink`). Параметр убирается из адреса после обработки.

## Добавить товар по ссылке (просьба пользователя)

Пользователь присылает ссылку на товар (например, Wildberries) и говорит, что это (куртка, кроссовки…). Нужно найти эту вещь на главном фото, вырезать её без фона и без модели и добавить в «Покупки» в нужную вкладку.

1. Окружение: `python3 -m venv /tmp/venv && /tmp/venv/bin/pip install -r scripts/catalog/requirements.txt`. Модели rembg скачиваются с GitHub при первом запуске. Сайты магазинов должны быть разрешены в сетевых настройках окружения (иначе попросить пользователя прислать фото файлом).
2. Посмотреть фото с сеткой: `/tmp/venv/bin/python scripts/catalog/add_item.py --wb <ссылка> --inspect /tmp/grid.png`, открыть `/tmp/grid.png` и найти вещь.
3. Вырезать с подсказками (доли 0..1 по сетке): `--box x1,y1,x2,y2` вокруг вещи, `--point x,y` на самой вещи (2–3 точки), `--exclude x,y` на том, что не нужно (волосы, лицо, руки, сумка). Сначала `--preview /tmp/cut.png` и посмотреть результат на тёмном фоне; поправить точки, если надо.
4. Без `--preview` скрипт кладёт `public/catalog/<id>.webp` и добавляет запись в `public/catalog/items.json` (`--list Одежда` — вкладка, создаётся сама; `--title`/`--price` можно задать вручную, если магазин их не отдал).
5. `npm test && npm run build`, коммит и пуш. После деплоя приложение само импортирует новую вещь на обоих телефонах (id детерминированный, удалённая вещь не вернётся).

Без `--box/--point` работает автоматический режим `--part upper|lower|full|object` (сегментация одежды rembg), но он грубее.
